> 每天一个随机挑战，让生活不那么无聊。读完一本书的一页？给陌生人一个微笑？试试看。

## ✨ 功能

- 🎲 每日随机挑战 — 每天刷新一个独特的挑战任务
- 🏷️ 多分类 — 运动 / 创意 / 社交 / 学习 / 趣味
- ✅ 完成任务 — 打卡标记，积累完成记录
- 📊 统计面板 — 你的挑战完成趋势
- 🔄 不满意可以重掷 — 每天限次
- 📱 响应式设计

## 🚀 快速开始

```bash
git clone https://github.com/PHclaw/RandomQuest.git
cd RandomQuest
npm install
npm run dev
```
